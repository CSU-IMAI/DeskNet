# DeskNest 1.0.0 — 分区透明度与备份还原修复

本次更新包含桌面分区外观改进，以及备份还原的跨盘路径修复。

## 分区透明度

- 程序区、文件区、加密区改为**径向透明度**：正中心更通透，向四周平滑变实，边缘更不透明。
- 分区默认面积增大到宽 `30%`、高 `38%`，内容显示空间更充足。
- 旧版默认尺寸的分区在升级时自动放大一次，保留原有位置与自定义布局。
- 设置 →「桌面工具」新增「分区统一透明度」滑杆：
  - 范围 `25%–95%`
  - 同时作用于程序区、文件区、加密区
  - 实时生效，无需重启
  - 自动持久化

## 备份还原修复

- 备份内的 `state.json` 不再固定写入资料库、备份目录的绝对盘符路径。
- 还原时以**当前程序数据目录**重新绑定资料库和备份目录，不再依赖备份时的 C 盘路径。
- 跨盘还原（例如程序数据在 C 盘、资料库在 E 盘）改为目录复制回退，不再因 `rename` 跨卷失败。
- 旧备份中的绝对路径会在还原时重定位到当前资料库、备份和快捷方式目录。
