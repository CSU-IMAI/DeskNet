# DeskNest 1.0.0 — 文件夹内容索引、开机自启动与备份还原

本次更新新增文件夹内容索引与目录监听，并包含开机自启动、分区透明度和备份还原修复。

## 文件夹内容索引与监听

- 文件区仍以文件夹为单位显示，不会把内部文件拆成一堆卡片。
- 每个文件夹项目会建立内部文件索引：文件名、相对路径、扩展名、大小、修改时间。
- **搜索以文件为结果对象**：搜索文件夹内部文件名时，返回的是具体文件，而不是笼统的文件夹。
- 搜索结果会显示文件名、所属文件夹和大小；点击可直接打开该文件，详情中也会显示所属位置。
- 文件夹详情仍会列出内部文件；文件区不会因此改变文件夹项目结构。
- 新增资料库目录监听：文件夹内新增、删除或修改文件后，约 1 秒内自动重建索引并同步到搜索。
- 兼容旧版本：已有文件夹无需重新导入，首次扫描或启动监听后即建立内容索引。
- 主界面顶部新增「扫描内容」按钮，可手动重新扫描全部保存内容并重建索引。

## 分区透明度

- 程序区、文件区、加密区改为**径向透明度**：正中心更通透，向四周平滑变实，边缘更不透明。
- 分区默认面积增大到宽 `30%`、高 `38%`，内容显示空间更充足。
- 旧版默认尺寸的分区在升级时自动放大一次，保留原有位置与自定义布局。
- 设置 →「桌面工具」新增「分区统一透明度」滑杆：
  - 范围 `25%–95%`
  - 同时作用于程序区、文件区、加密区
  - 实时生效，无需重启
  - 自动持久化

## 备份还原修复

- 备份内的 `state.json` 不再固定写入资料库、备份目录的绝对盘符路径。
- 还原时以**当前程序数据目录**重新绑定资料库和备份目录，不再依赖备份时的 C 盘路径。
- 跨盘还原（例如程序数据在 C 盘、资料库在 E 盘）改为目录复制回退，不再因 `rename` 跨卷失败。
- 旧备份中的绝对路径会在还原时重定位到当前资料库、备份和快捷方式目录。

## 开机自启动

- 设置 →「启动」新增「开机自启动」开关，默认关闭。
- 开启后写入当前用户的 Windows 启动项，登录后自动运行 DeskNest。
- 开机启动使用 `--autostart` 参数，静默启动到系统托盘，不弹出主窗口。
- 移动安装目录或便携版位置后，下次启动会自动更新启动项路径。
- Linux 同步使用 `~/.config/autostart` 的 `.desktop` 启动项。
